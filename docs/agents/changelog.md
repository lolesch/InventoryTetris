# Changelog

The player-facing Changelog is `Assets/Changelog/Changelog.md`; its terms are in `GLOSSARY.md`
("Changelog").

- A change a player would notice adds a bullet under `Unreleased` in Patch Notes, in the same change.
- Fixing a Known Issue or shipping a Roadmap item removes it from its list in that same change.
- A version bump renames `Unreleased` to the version and date.
- The Icebox (`dev/Icebox.md`) stays private: an idea reaches the Roadmap only reworded for players,
  never with internal vocabulary.
